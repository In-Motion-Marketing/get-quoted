# Contributing

Pull requests are welcome, especially platform updates. Sites change their prices, limits, and rules often.

## Updating or adding a platform

1. Edit or add a file in `get-quoted/references/`. Copy `haro.md` as a template for a new one.
2. Cover: who it suits, cost to experts, how queries arrive, answer length, AI rules, and how submission works.
3. Cite your sources in the `## Sources` list at the bottom, with the platform's own help, pricing, or terms pages first. Update the "Last checked" line.
4. For a new platform, add a row to the table under "Platform notes" in `get-quoted/SKILL.md`, including its **Mode** (Draft, Coach, or Check each request). Choose Coach if the platform bans or strongly discourages AI-written answers.
5. Add it to the platform table and file list in `README.md`.

If you can't confirm something, write "unconfirmed" rather than guessing.

## Changes this project won't accept

The skill exists to help experts get quoted for real expertise, not to send more pitches. Please don't send changes that:

- Let the skill submit, send, post, or follow up on the user's behalf
- Scrape platforms, inboxes, or email digests in bulk, or browse logged-in sites on the user's behalf
- Draft answers without an interview, or for a batch of questions at once
- Loosen the fit test or remove skip rules
- Help get around a platform's AI detection, limits, or account rules
- Add claims about guaranteed placements or win rates

## Style

Plain US English, short sentences, no em dashes, straight quotes. Keep `SKILL.md` short. Detail belongs in the reference files.
