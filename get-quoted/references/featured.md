# Featured

Last checked: November 2026.

- **Site:** https://featured.com. Same owner as HARO and Connectively
- **What it is now:** since June 2026, an AI assistant for PR that searches journalist requests across HARO, Connectively, Qwoted, Substack, X, LinkedIn, and other sources. Its old expert Q&A queue moved to Connectively
- **Cost:** free plan, plus paid plans
- **Best for:** PR teams, founders, and agencies who also want podcasts, bylines, speaking slots, and awards

## How to work with it

Featured gathers requests from many sources. It does not run its own queue. Each pitch must follow the rules of the platform it came from, so read that platform's reference file:

- From Connectively: `connectively.md`
- From HARO: `haro.md`
- From Qwoted: `qwoted.md`
- From X, LinkedIn, Bluesky, or Substack: `journorequest.md`

Each request in Featured shows a response URL or email, a deadline, and whether the outlet accepts AI-assisted answers (yes, no, or unknown). If it says no or unknown, use coach mode. If this flag and the source platform's file disagree, use the stricter one.

## Rules

Featured's acceptable use policy requires a qualified person to review AI output before it reaches a journalist, AI use to be disclosed where the recipient requires it, and no made-up quotes or statistics. The user sends or submits every pitch themselves, through the response URL or email the request shows.
