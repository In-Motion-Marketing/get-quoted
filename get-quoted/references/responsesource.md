# ResponseSource (Journalist Enquiry Service)

Last checked: November 2026. Confirm pricing and eligibility on the site.

- **Site:** https://www.responsesource.com/pr/journalistenquiry/. Part of Pulsar Group, alongside Vuelio
- **Best for:** UK national, regional, trade, consumer, and broadcast media, across about 25 categories
- **Who can use it:** built for PR professionals and organizations, not individual experts. Subscriptions are priced per category per year. Most experts reach it through their PR agency or in-house comms team. If the user is the PR person, it fits
- **How queries arrive:** email, filtered by category, media type, and sender type. Requests go out within about an hour during UK weekday business hours. Deadlines can be as short as one hour

## Answer format

- No published length limit. Use the default: short, about 4 sentences
- Nothing is attached automatically. Include the expert's name, title, company, brief credentials, and contact details
- Mention which request you are answering
- Avoid attachments. ResponseSource says they annoy journalists. Offer a link instead
- Don't attach a press release or turn the reply into a sales pitch

## Submitting

Each request has a "How to reply" link that opens an email with the subject pre-filled. The user sends it from their own email client. Draft the subject and body. Never send it yourself. The user sends from their own inbox.

## Context

Journalists using the service check credentials closely and are wary of AI-written replies, so keep the answer in the expert's own words and make the credentials easy to verify.

ResponseSource's own tips: reply fast, stay on topic, use plain language, find a distinct angle, use data sparingly, have the spokesperson ready, and don't chase.
