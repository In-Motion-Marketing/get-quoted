# #journorequest, social media requests, and journalist emails

Last checked: November 2026.

Journalists post requests publicly with hashtags such as #journorequest, #prrequest, #mediarequest, and #bloggerrequest on X, Bluesky, LinkedIn, and Threads. Most #journorequest traffic is from the UK. There is no platform, no account, and no moderation. The same checks apply when a journalist emails the user directly asking for a source.

## Before shortlisting

- **Check the poster is real.** Confirm the journalist and the outlet exist. Posts are unvetted, and some are fishing for free content
- **Find the deadline.** Posts are short and often leave it out. If there is none, ask the user or treat it as 24 to 48 hours
- **Find the reply channel.** Follow the post's instructions. If there are none, look for an email address on the journalist's profile

## Answer format

- Default: short, about 4 sentences
- Name the request in the subject line or first line. Journalists often have several open at once
- Nothing is attached, so end with name, title, company, one link, and how to reach the expert
- For email, use a plain subject line that names the request

## Submitting

- Email is the preferred channel for most journalists. Use a DM only if the post asks for one
- Never call or text without permission
- Never post, reply, or DM for the user. Draft the text for them to send themselves
- Follow up once at most, and only if the user wants to

## What annoys journalists

- Loosely related pitches. Only answer if the expert fits the request closely
- Vague offers such as "I have some experts who could help"
- Fast or repeated chasing
- Case studies that sound too neat to be real
- AI-written replies. Journalists say they can tell. Keep it in the expert's own words

## Tools that collect these posts

The user can save searches for these hashtags on X, Bluesky, and LinkedIn, or use a third-party alert tool. Work from requests the user pastes in.
