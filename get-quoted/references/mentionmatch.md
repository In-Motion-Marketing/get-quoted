# MentionMatch (formerly Help a B2B Writer)

Last checked: November 2026. Confirm details on the site.

- **Site:** https://mentionmatch.com. The old helpab2bwriter.com redirects there. Run by Superpath. Requests at https://mentionmatch.com/requests
- **Best for:** B2B topics such as marketing, SaaS, sales, SEO, content, CRO, email, analytics, design, AI, ecommerce, and DTC. Requests come from writers at B2B blogs and content sites, not news outlets, so expect a quote in an article, not press coverage. Open to experts anywhere
- **Cost:** free for sources. A paid API tier gets requests without the free tier's delay of about a day
- **How queries arrive:** email, filtered to the expertise areas the expert picks

## Rules

- MentionMatch says it bans accounts that send AI-written replies, and every request email has a spam-report button
- No advertising
- MentionMatch's own advice: send fewer, more thoughtful responses

Use coach mode (see SKILL.md): every email carries a spam button and AI-written replies can get the account banned, so the expert writes the reply in their own words. Only take requests where they have a real story or number.

## Answer format

- No published length limit. Use the default: short, about 4 sentences
- Writers want a unique quote written for their specific article. Never reuse an answer
- Include the expert's name, title, company, and one link so the writer can credit the source

## Submitting

The expert replies to the request email. In coach mode (see SKILL.md), the expert writes the reply. Never send it yourself. The user sends from their own inbox.
